# Hitungin

Kalkulator finansial Indonesia dengan hasil transparan, asumsi jelas, dan sumber aturan yang dapat diverifikasi.

> Status: Discovery / MVP planning. Belum siap untuk keputusan finansial nyata.

## MVP
- Kalkulator gaji: gross/net, PPh 21, BPJS, THR
- Kalkulator cicilan: flat dan efektif/anuitas
- Kalkulator tabungan: target dan compounding
- Kalkulator investasi: skenario dan proyeksi ilustratif
