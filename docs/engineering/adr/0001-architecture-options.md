# ADR-0001 — Architecture options

Status: Proposed | 2026-10-19

Options: (A) static web app + pure client-side formulas, (B) web app + API (e.g. Go), (C) hybrid.

Criteria: maintainability, cost, deployment, formula updates, performance, privacy, future authentication and premium features.

Decision: Pending Sprint 0 spike and requirements review. Do not treat this ADR as accepted.
