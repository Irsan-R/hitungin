# Testing strategy

- Unit tests for formulas with reference fixtures and boundary cases.
- Golden cases cross-checked against authoritative rules/examples where available.
- Integration tests for UI-to-calculation mapping.
- End-to-end tests for key user journeys and mobile viewports.
- Accessibility checks for keyboard navigation, labels and contrast.
- CI lint, test and build checks after stack selection.
- Version rule changes and retain regression fixtures.
